# 验证手册 · 第 1 步（零成本）：UU 被控 + 手机麦克风直连闭环

> 目标：在**不买 VPS、不注册域名**的前提下，先确认"个人 Mac 能被控 + 手机能当麦克风让 Mac 听见你"这条语音闭环在你环境真通。
> 为什么先做这步：后面买腾讯云香港 VPS、跑 uurc-web、配 Caddy 都建立在"UU 被控 + 手机麦克风直连"可用之上。先零成本验证，避免在投钱后发现底层不通。
> 范围：**只验证，不部署网页端、不碰 iOA 公司 Mac**。全程在你个人 Mac + 手机上操作。
> 证据基线：uurc-web 源码确认需 UU 账号登录；UU 官方"麦克风直连"= 手机麦作被控 Mac 麦（已在 §13.4b 记录）。

---

## 前置确认（先答自己这几个问题）

- [ ] 被控机 = **个人 Mac**（macOS Sonoma+），**不是**公司 iOA Mac（iOA 会拦远控，见 §13.10 腾讯 iOA 核查）
- [ ] 有一台智能手机（iOS/Android 均可），能装 UU 远程 APP，且有蜂窝网络（独立出口，不依赖车机）
- [ ] 有一个 **UU 账号**（手机号可收短信注册）
- [ ] 车不在手边也能先验证"被控+麦克风"（车机验证放到第 2 步买 VPS 之后）

---

## 步骤

### 1. 个人 Mac 装 UU 客户端并开被控
- 下载 UU 远程（网易，uuyc.163.com/download），装到个人 Mac。
- 登录 UU 账号。
- 打开"允许本设备被控"，按提示授予 **屏幕录制 + 辅助功能** 系统权限（系统设置 > 隐私与安全性）。
- 确认 Mac 在线、出现在你账号的设备列表里。

### 2. 手机装 UU APP 控这台 Mac（验证"被控闭环"）
- 手机装 UU 远程 APP，登录**同一 UU 账号**。
- 设备列表里选你的个人 Mac → 发起控制。
- 验证：手机能看 Mac 画面、能触屏/虚拟键鼠操作 Mac。
- ❌ 若这步不通 → 先排查 UU 账号/权限/网络，**不要继续往下**，底层远控就有问题。

### 3. 开"麦克风直连"（验证"语音闭环"）
- 在手机 UU 控制 Mac 的会话里，开启 **麦克风直连**（uu 官方博客 micophone.html 所述：手机麦作为被控 Mac 的麦克风）。
- 在 Mac 上打开任意能收音的程序（语音备忘录 / 或后面要用的 Claude Code / Cursor 的语音输入 / 系统听写），手机对着自己说话。
- 验证：Mac 侧程序**确实收到了手机这边的声音**。
- ❌ 若不通 → 查 UU APP 内"麦克风直连"开关位置、手机系统是否给 UU APP 麦克风权限。

### 4. 模拟"车里 vibecoding"的最小形态（可选但强烈建议）
- 在 Mac 上打开你的 coding agent（Claude Code / Cursor / Aider）。
- 手机开麦克风直连，对着手机说一句指令（如"在 src 下新建一个 hello.ts"）。
- 验证：Mac 上的 agent 是否真的"听见并执行"了你的语音。
- 这一步决定你后面整套方案**有没有意义**——如果语音→Mac agent 这环不稳，车机网页端再顺也白搭。

---

## 验证通过标准（全绿才进第 2 步）

| 检查项 | 通过标准 |
|---|---|
| 被控 | 手机能看并操作个人 Mac |
| 屏幕录制/辅助功能授权 | Mac 已授予 UU，控制无黑屏/无拒操 |
| 麦克风直连 | Mac 侧程序收到手机声音 |
| 语音→agent | 手机说话，Mac 上 coding agent 执行了指令 |

## 任一红 → 止步原因与去向

- **被控不通**：UU 账号/权限/版本问题 → 先解决 UU 本身，或换 ToDesk/向日葵同法验证（商业网页端路线）。
- **麦克风直连不通**：查 UU APP 内开关 + 手机麦克风权限；若 UU 此功能在你版本缺失，则语音改走"手机 STT → 注入服务"（§13.4a），车机方案仍可行但需第 2 步多一个注入端点。
- **语音→agent 不稳**：是识别/网络问题，与远控无关，先调 STT 源（豆包/讯飞/whisper）再继续。

## 通过后下一步（第 2 步，才花钱）

1. 买**腾讯云国际站香港** Lighthouse（2C2G/4G，30Mbps 峰值，Ubuntu 22.04）。
2. 注册域名（DNSPod）+ Let's Encrypt 证书（车机拒自签）。
3. VPS 跑 `uurc-web`（Docker 或本地 build）+ Caddy（basic_auth 双重保险）。
4. 车机浏览器开 `desktop.你的域名.com` 控 Mac，验证画面+软键盘。
5. 车机仅看画面+偶尔触屏；语音交给手机 UU 麦克风直连。

> 第 2 步细节见后续部署票（待第 1 步全绿后产出）。本手册只负责"零成本验证底层闭环"。
